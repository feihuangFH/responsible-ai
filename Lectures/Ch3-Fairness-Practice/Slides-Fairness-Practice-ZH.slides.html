工作流程可视化

案例研究:车险公平定价

  • 100,000份法国车险第三方责任险保单
  • 响应变量:纯保费 = 频率 × 严重程度
  • 受保护属性:性别
  • 合法变量:年龄、无赔款折扣等级、车辆组别、密度、价值
  • 非合法变量:InsuranceScore,一个构造出的类信用评分代理变量

纯保费大致相当于每份保单的平均预期理赔成本。频率是指保单持有人提出理赔的频繁程度,严重程度是指每次理赔的平均成本。第三方责任险承保的是保单持有人对他人造成的伤害或损失,不包括其自身车辆。无赔款折扣等级有时称为 bonus-malus,数值越低表示过去理赔次数越少。

InsuranceScore 代表了一类富含代理信息的因子:保留预测价值,可能与性别相关,受到更严格的公平性审查。它也具有实际用途。差异性影响消除器需要连续型输入变量,因此将分类型代理变量汇总为单一评分,使得在 MCDP 下进行去偏处理成为可能。

五种模型

模型 准则 方法
M0 基准 完整模型,包含性别变量
MU FTU(无意识公平) 移除性别变量
MDP 人口统计学均等性 所有预测变量均去偏
MCDP 条件 DP 仅对 InsuranceScore 去偏
MC CPV(控制受保护变量) 完整模型,评分时对性别取平均

每种模型均分别以 GLM(Poisson 频率 + Gamma 严重程度)和 XGBoost 拟合。

第二部分——拟合模型

预处理:差异性影响消除器

对于 MDP 与 MCDP,调整连续预测变量的分布,使其不再依赖于性别,同时保留总体形态。

di_data <- disparate_impact_remover(
  data = data_for_di, protected = as.factor(data$Gender),
  features_to_transform = features_to_transform, lambda = 1
)
  • MDP:应用于所有预测变量
  • MCDP:仅应用于 InsuranceScore

GLM 频率—严重程度框架

\text{纯保费} = \text{理赔频率} \times \text{理赔严重程度}

  • 频率:Poisson GLM,对数链接函数,风险敞口偏移量
  • 严重程度:Gamma GLM,对数链接函数,仅基于理赔数据

年龄以一个灵活的函数形式(\text{Age}, \log(\text{Age}), \text{Age}^2, \text{Age}^3, \text{Age}^4)纳入模型。

风险敞口是指保单处于有效状态、面临理赔风险的天数,用于对理赔次数进行标准化。XGBoost 采用相同的预测变量集以相同方式拟合,频率部分使用 count:poisson 目标函数。所有模型均按比例缩放,使预测保费总额与 GLM MU 的组合总额(全部保单预测保费之和)相匹配。这样比较的重点便落在重新分配上,而非组合层面的总体差异。

第三部分——结果

公平性指标

差异性影响比率(DIR):\dfrac{\mathbb{E}(\hat{Y} \mid X_P = b)}{\mathbb{E}(\hat{Y} \mid X_P = a)}

  • 接近1 = 各群体间平均保费相近
  • 五分之四原则:期望落在0.8–1.25之间

RMSE(准确性,越低越好)

差异性影响比率正是我们在此检验人口统计学均等性的方式,即预测结果在受保护群体间平均而言不应存在差异这一理念。

公平性—准确性权衡取舍

虚线 = DIR 为1(最公平)。点线 = 五分之四区间。位置更靠左(RMSE 更低)的点更为准确。M0 落在公平区间之外,准确性也最差。MDP、MCDP、MC 均落在区间内,准确性代价很小。关键发现:MCDP 与 MC 实现了接近1的 DIR,相对于 M0 的准确性损失却很有限。

解读该图

  • M0(红色):最准确,最不公平,DIR 为1.36,超过五分之四原则的上限
  • MU(橄榄色):移动幅度足以落入公平区间,但超调越过 DIR = 1(降至0.92),导致哪一方支付更多发生反转
  • MDP、MCDP、MC:落在公平区间内,准确性代价很小
  • 在每一个公平性水平上,XGBoost(▲)相对于 GLM(●)都保留了大部分优势

这里公平性的代价是真实存在的,但幅度很小。

第四部分——保费重新分配

谁获益,谁受损?

将每一个公平模型与MU(行业标准基准模型)进行比较:

\text{相对保费差异}_{i} = \frac{\bar{Y}_{\text{模型},i} - \bar{Y}_{\text{MU},i}}{\bar{Y}_{\text{MU},i}}

正值 = 公平模型收取更高保费 · 负值 = 收取更低保费

按年龄和性别划分的保费重新分配

解读该图

  • MDP:转移最为明显,在大多数年龄段内提高原本收费较低群体的保费,降低原本收费较高群体的保费
  • MCDP:与 MU 最为接近,合法变量保持不变,仅代理变量被去偏
  • MC:重新分配程度居中,仅反映 M0 中的性别系数

团结互助原则:准则越严格,群体间的交叉补贴就越多。

第五部分——案例研究:审前风险评估(COMPAS)

案例情境

美国某县正在决定是否续签一份审前风险评估工具的合同,该工具用于协助法官设定保释与释放条件。

  • 被认为有效减少了不必要的审前羁押
  • 一项独立审计发现,该工具过度将不会再犯的黑人被告标记为高风险
  • 该县首席公设辩护人必须做出判断:它是否符合站得住脚的公平性标准?能否在不使其失去实用价值的前提下加以修正?

这一情境呼应了针对真实 COMPAS 工具的 ProPublica 调查报道。民权倡导者主张废除该工具;供应商与部分法官则认为它仍优于不加结构的人工判断。

从定价到分类

以上内容全部是回归问题(连续型成本)。而这一决策是二元的:释放/羁押、标记/放行。

M0/MU 框架原封不动地适用。改变的只是模型类型和指标。

  • N = 5,278名被告(2,103名白人;3,175名非裔美国人)
  • 响应变量:两年内再犯 · 受保护属性:族裔
  • 基础再犯率已存在显著差异:39.1% 对比52.3%

再犯是指出狱后因新罪行而被逮捕。这里的两年内再犯是指在出狱后两年内。

拟合 M0 与 MU

m0 <- glm(Two_yr_Recidivism ~ Number_of_Priors + Age_Above_FourtyFive +
            Age_Below_TwentyFive + Female + Misdemeanor + ethnicity,
          data = compas_data, family = binomial)

mu <- glm(Two_yr_Recidivism ~ Number_of_Priors + Age_Above_FourtyFive +
            Age_Below_TwentyFive + Female + Misdemeanor,
          data = compas_data, family = binomial)

M0 直接包含族裔变量。MU 移除了该变量,与实际的 COMPAS 工具做法一致。

三项公平性检验

准则 M0 差异比率 MU 差异比率
人口统计学均等性 2.11 1.94
机会均等/TPR 差距 1.75 1.67
预测率均等性/精确率差距 1.11 1.15

无意识几乎没有改变任何东西。 MU 几乎不损失准确率(66.5% 对比66.8%)。每一项差异比率都几乎原封不动地保留了下来。

只要模型预测的再犯概率高于此处设定的0.5分界值,该被告便被计为标记为高风险。一名不会再犯的非裔美国被告,被标记为高风险的概率大约是一名不会再犯的白人被告的两倍(FPR:MU 下为33.0% 对比17.2%),这与 ProPublica 针对实际工具所报告的发现在性质上完全一致,在这里用一个简单的逻辑回归模型便复现了这一结果。

为什么这三项检验会出现分歧?

重要

人口统计学均等性忽略真实结果。它同时完全反映了基准率差距(39.1% 对比52.3%)以及模型本身的不公平。精确率以预测结果为条件,部分吸收了这一差距。

这正是第二章的不可能性结论在真实数据上的体现:当基准率不同时,分离性与充分性无法同时成立。选择一项准则,就是在选择基准率差异中有多少应被计入“不公平”,又有多少应被视为“信号”。

后处理:roc_pivot()

这一拒绝选项修正,对落在分界值附近、宽度为 theta 的区间内的预测结果重新贴标签,给予处于弱势群体的边界个案以有利推定。

  • 机制:以分界值为中心镜像翻转边界概率(p \to 2\cdot\text{分界值} - p)——优势群体中刚好落在”有利”一侧的边界个案翻转为不利;弱势群体中刚好落在”不利”一侧的边界个案翻转为有利。区间之外、模型有把握的预测保持不变。
theta 准确率 人口统计学均等性 TPR 差距 精确率差距
0(MU) 66.5% 1.94 1.67 1.15
0.05 65.7% 1.13 1.11 1.31
0.10 62.8% 0.63 0.69 1.45
0.20 56.8% 0.23 0.30 1.73

解读这一权衡取舍

重要

将人口统计学均等性和 TPR 差距推向1,并不会让精确率保持不变——反而会主动使其恶化(1.15 → 1.73)。超过 theta ≈ 0.10 之后,修正会下冲并反转差异,同时准确性代价陡增。

没有任何 theta 能够同时满足这三项检验,因为只要基准率存在差异,这样的值就根本不存在。后处理让你可以选择落在这条曲线上的哪个位置,但无法让你逃离这条曲线本身。

💬 讨论(5分钟)——总结

后处理可以在某一项准则上调高公平性,但总是以牺牲另一项为代价。

如果你必须为一个实际部署的系统选定一个 theta 值,你会如何决定在哪里停下?

小结

  • 全部四种设计都能在真实数据上以有限的准确性代价实现,同样的工作流程也可迁移至分类问题(COMPAS)
  • 模型的选择应当遵从监管准则,而非建模上的便利性
  • MDP:群体公平性最强,重新分配幅度最大。MCDP:更具针对性
  • 无意识(MU)本身很少足够
  • 后处理可以命中某一项准则,但永远无法同时命中全部三项
