作者

学习目标

  • 端到端地将某一项已选定的公平性准则付诸实践:选定一个干预阶段,加以实现,并同时衡量公平性与准确性。
  • 在一个实例案例研究上,实现第二章中的 MU、MDP、MCDP 与 MC 模型设计(GLM 与 XGBoost)。
  • 使用差异性影响比率与 RMSE,衡量公平性—准确性权衡取舍。
  • 解读结果在受保护子群体与合法子群体间的重新分配。
  • 将同一套 M0/MU 框架应用于一个二元分类问题,使用标准的分类公平性指标(人口统计学均等性、均衡赔率、预测率均等性)。
  • 对一个分类器应用后处理修正(roc_pivot),观察这一修正在各准则之间(而不仅仅是相对于准确性)所带来的权衡取舍。

从原则到实践

第二章介绍了选择哪一种公平性准则,以及哪一种模型设计(M0、MU、MDP、MCDP、MC)能够落实该准则。将这一选择转化为一个可运行的系统,无论在哪个领域,都遵循相同的步骤:

  1. 确定准则以及该准则所适用的结果变量(第二章,第一步)。
  2. 选择干预阶段(预处理、处理中或后处理)以及相应的模型设计(第二章,第二步)。
  3. 实现并拟合模型,保留一个基准模型(M0)用于比较。
  4. 衡量权衡取舍:将一项公平性指标(如差异性影响比率)与一项准确性指标(如 RMSE)对照评估,而非孤立看待。
  5. 审视重新分配:相对于当前基准,哪些子群体获益,哪些子群体受损。
  6. 对逆向选择进行压力测试(选读深度):检验更公平的模型是否在某个实际结果偏向其中一个模型的细分市场上,与基准模型系统性地不一致。有关这一步骤的双升力图(double-lift-chart)实例分析,请参见 fair.feihuang.org 的案例研究:公平模型。

本讲座将在一个实例案例研究上,完整展开第3至5步,因此上述每一步都会有一个具体的实现可供参照。

案例研究:车险公平定价

设想一家中型法国车险公司,其首席精算师必须在一个新的定价模型投入生产之前,对其签字批准。从 Colorado 的 SB21-169 到欧盟的统一性别定价规则,多个市场的监管机构如今都要求保险公司在部署前证明,其定价模型不会使某个受保护群体遭受不公平的不利影响。无论哪种方向出错,代价都很高昂。一个不公平的模型面临罚款、诉讼与声誉损害的风险,而一个矫枉过正的模型则可能错误定价风险、侵蚀盈利能力。首席精算师需要一种站得住脚的方法,在选定模型之前,同时就公平性和准确性对各种模型设计进行比较。

我们以 Fair Pricing Playbook (Huang 2026年) 中的案例研究:公平模型作为实例,该案例基于 Xin 和 Huang (2024年) 中的模型设计与实证结果。上述工作流程(确定准则 → 选择阶段 → 拟合 → 衡量权衡取舍 → 审视重新分配 → 压力测试)同样适用于招聘、信贷或医疗资源分配模型。

我们使用法国车险数据,比较五种定价模型,从一个完整基准模型到四种反歧视设计,分别使用 GLM 和 XGBoost 实现。

为什么将 InsuranceScore 作为非合法变量?

Xin 和 Huang (2024年) 中的基准情形,将 InsuranceScore 视为唯一的非合法变量。它代表了一类富含代理信息的因子(如基于信用记录的保险评分),这类因子:

  • 对理赔风险仍保留一定的预测价值
  • 可能与受保护属性(性别)相关
  • 在某些监管制度下会受到更严格的公平性审查

这一构造方式也具有实际用途。差异性影响消除器要求连续型输入变量,因此将分类型代理变量汇总为单一评分,使得在 MCDP 下进行去偏处理成为可能。

预处理

使用差异性影响消除器去偏

对于 MDP(模型3)和 MCDP(模型4),我们使用 fairmodels R 包中实现的差异性影响消除器 (Feldman 等 2015年) 对预测变量进行预处理。

该消除器调整连续变量的分布,使其不再依赖于受保护属性(性别),同时保留总体分布形态。

  • MDP:应用于所有选定的预测变量(年龄、无赔款折扣等级、价值、密度、GroupOne、InsuranceScore)
  • MCDP:仅应用于非合法变量(InsuranceScore)

在去偏之前,会向有序变量添加少量随机噪声,以避免出现取值相同的问题。去偏之后,有序变量会被重新映射回其原始的因子水平。

展示情形设定与辅助函数定义 
# InsuranceScore 是唯一被视为"非合法"(代理变量)的预测变量;
# glm_predictors 中其余变量均视为合法。这一区分正是 MDP(全部去偏)
# 与 MCDP(仅对 non_legitimate 去偏)的差异所在。
non_legitimate <- c("Insurancescore")

glm_predictors <- c("Age.ct", "Bonus", "Value", "Density", "GroupOne", "Insurancescore")
xgb_predictors <- glm_predictors

# 将连续的 Age(以年为单位)转换为 "18-22"、"23-27" 等年龄段标签。
# 之所以需要这一步,是因为下文的去偏步骤将 Age 当作连续变量处理,
# 而 GLM 使用的是分类(分段)版本的 Age,因此去偏后需要重新分段。
make_age_group <- function(age) {
  cut(age,
    breaks = c(-Inf, 22, 27, 32, 37, 42, 47, 52, 57, 62, 67, Inf),
    labels = c("18-22","23-27","28-32","33-37","38-42","43-47","48-52","53-57","58-62","63-67","68+"),
    right = TRUE)
}

# 将一个连续(去偏后)的变量四舍五入回最接近的原始整数水平,并裁剪到
# [min_level, max_level] 范围内。用于将 Bonus 与 GroupOne 从去偏步骤中的
# 连续处理方式,还原为它们原本的离散类别。
bin_to_factor <- function(x, min_level, max_level) {
  levels <- min_level:max_level
  x <- pmin(pmax(x, min_level), max_level)        # 裁剪:不低于 min_level,不高于 max_level
  cuts <- c(min_level - 0.5, levels[-1] - 0.5, max_level + 0.5)
  as.factor(as.numeric(cut(x, breaks = cuts, labels = levels, include.lowest = TRUE)))
}

# 构建 data 的去偏版本:对 features_to_transform 中指定的列(MDP 对应全部预测变量,
# MCDP 仅对应 InsuranceScore)运行 disparate_impact_remover(),使其分布不再依赖于 Gender。
make_di_removed_data <- function(data, features_to_transform, lambda = 1) {
  data_for_di <- data %>%
    # disparate_impact_remover() 需要连续型输入,因此这里将当前为分类变量的
    # Bonus 与 GroupOne 临时转换为数值型。
    mutate(GroupOne.ct = as.numeric(GroupOne), Bonus.ct = as.numeric(Bonus))

  # 添加微小随机噪声(jitter)以打破重复取值之间的并列关系,这是去偏算法
  # 对观测值排序所需要的。每个变量的最小值与最大值保持不变(keep),
  # 以保证取值范围不发生改变。
  jitter_keep_minmax <- function(x, factor = 1) {
    keep <- x == min(x, na.rm=TRUE) | x == max(x, na.rm=TRUE)
    x[!keep] <- jitter(x[!keep], factor = factor)
    x
  }

  # 对下文将要去偏的每一个变量,应用 jitter_keep_minmax()。GroupOne.ct 使用了
  # 更大的 factor(5),因为它是一个粗粒度的整数编码,并列取值比其他变量多得多,
  # 因此需要更强的噪声才能打破这些并列关系。
  data_for_di <- data_for_di %>%
    mutate(
      Age.ct = jitter_keep_minmax(Age.ct, factor=1),
      Bonus.ct = jitter_keep_minmax(Bonus.ct, factor=1),
      Value = jitter_keep_minmax(Value, factor=1),
      Density = jitter_keep_minmax(Density, factor=1),
      GroupOne.ct = jitter_keep_minmax(GroupOne.ct, factor=5),
      Insurancescore = jitter_keep_minmax(Insurancescore, factor=1)
    )

  # 真正执行去偏的一步:调整 features_to_transform 中每一列的分布,使其对每个
  # Gender 群体而言都相同。lambda = 1 表示施加完全修正(lambda = 0 则保持数据不变)。
  di_data <- disparate_impact_remover(
    data = data_for_di, protected = as.factor(data_for_di$Gender),
    features_to_transform = features_to_transform, lambda = lambda
  )

  # 将 Age、GroupOne、Bonus 从去偏后的连续取值,转换回 GLM 所需要的分类分段,
  # 使用上文定义的两个辅助函数。
  di_data <- di_data %>%
    mutate(
      Age = make_age_group(Age.ct),
      Age = as.factor(as.numeric(Age)),
      GroupOne = bin_to_factor(GroupOne.ct, 1, 20),
      Bonus = bin_to_factor(Bonus.ct, 1, 21)
    )
  di_data
}

# glm() 的简单封装,固定了频率—严重程度框架中每一部分所用的分布族:
# 理赔严重程度(成本,恒为正,右偏)用 Gamma;理赔频率(计数)用 Poisson。
# 封装后无需在下文四种模型设计对应的八次 glm() 调用中,每次都重复 family=... 参数。
fit_gamma_model  <- function(formula, data) glm(formula, family=Gamma(link="log"), data=data)
fit_poisson_model <- function(formula, data) glm(formula, family=poisson(link="log"), data=data, offset=log(Exppdays))

# 将一组原始预测保费按比例缩放,使其总额与某个参考组合的总额一致
# (用于下文,使各模型的整体业务规模具有可比性,差异仅体现在保费在保单持有人之间的*分布*上)。
adjust_to_base_portfolio <- function(raw_premium, base_premium) raw_premium * sum(base_premium) / sum(raw_premium)

# XGBoost 需要数值矩阵,而非包含因子的数据框,因此这里将每个分类预测变量
# 转换为 0/1 哑变量列(model.matrix()),并删除 XGBoost 不需要的列
# (即结果变量,以及冗余的参照水平列 GenderMale)。
make_xgb_design <- function(data) {
  # 以下每一项被剔除的原因各不相同,并非因为 XGBoost 无法处理它们:
  # - "Age":年龄的分段/分类版本。模型实际使用的是连续版本 Age.ct(予以保留),
  #   因此 Age 只是重复了同一信息。
  # - "GroupOne.ct" 与 "Bonus.ct":GroupOne 与 Bonus 的连续数值版本,是差异性
  #   影响消除器内部计算过程中遗留下来的列(仅存在于去偏后的数据
  #   ClaimsData_DIremv 中)。模型实际使用的是分类版本的 GroupOne 与 Bonus
  #   (予以保留)作为真正的定价因子,因此这两列会与之重复。
  # - "Female":Gender 的0/1重复版本,仅供别处的 MC 性别取平均步骤使用;
  #   下文的 model.matrix() 已经会对 Gender 本身进行独热编码。
  # - "ClaimSeverity":GLM 严重程度模型的结果变量。XGBoost 的严重程度目标
  #   变量用的是 Indtppd,因此 ClaimSeverity 绝不能作为预测变量出现,
  #   否则会将答案泄漏给模型。
  xgb_unused <- c("Age","GroupOne.ct","Bonus.ct","Female","ClaimSeverity")
  data %>%
    select(-any_of(xgb_unused)) %>%
    model.matrix(~ 0 + ., data=.) %>%
    as.data.frame() %>%
    select(-any_of("GenderMale"))
}

# 将预测变量矩阵打包为 XGBoost 训练/预测函数所需要的 xgb.DMatrix 格式。
# base_margin 在对数尺度上提供一个已知的偏移量(例如频率模型的风险敞口,
# 或严重程度模型所用的已拟合频率),这样 XGBoost 只需学习剩余的模式,
# 而无需学习偏移量本身。仅在评分(而非训练)时省略 response。
make_xgb_dmatrix <- function(data, response=NULL, base_margin, drop_vars) {
  x <- data %>% select(-any_of(drop_vars)) %>% as.matrix()
  if (is.null(response)) dmat <- xgb.DMatrix(x)
  else dmat <- xgb.DMatrix(x, label=data[[response]])
  setinfo(dmat, "base_margin", log(base_margin))
  dmat
}

# 确保新数据集拥有与 XGBoost 训练数据完全相同、顺序也一致的哑变量列
# (new_data 中缺失的列填充为0)。之所以需要这一步,是因为如果某个类别
# 恰好只出现在训练数据或评分数据中的一个,model.matrix() 可能会为二者
# 生成略有不同的列。
align_xgb_design <- function(new_data, train_data) {
  missing_cols <- setdiff(names(train_data), names(new_data))
  if (length(missing_cols) > 0) new_data[missing_cols] <- 0
  new_data[, names(train_data), drop=FALSE]
}

拟合模型

GLM 频率—严重程度框架

GLM 和 XGBoost 均采用频率—严重程度分解:

\text{纯保费} = \text{理赔频率} \times \text{理赔严重程度}

  • 频率:采用对数链接函数与风险敞口偏移量的 Poisson GLM(风险敞口是指保单处于有效状态、面临理赔风险的天数)
  • 严重程度:采用对数链接函数的 Gamma GLM(仅基于发生理赔的数据拟合)

按照 Schelldorfer 和 Wuthrich (2019年) 的做法,年龄以连续函数形式(\text{Age}, \log(\text{Age}), \text{Age}^2, \text{Age}^3, \text{Age}^4)纳入模型。

拟合 GLM 模型 
# sev_formula_m1 是包含 Gender 的严重程度公式(用于 M0);update(..., . ~ . - Gender)
# 在已有公式的基础上移除 Gender,而无需重新输入一遍,由此得到 sev_formula_m2
# (用于不将 Gender 作为直接预测变量的 MU、MDP、MCDP)。
sev_formula_m1 <- ClaimSeverity ~ Age.ct + log(Age.ct) + I(Age.ct^2) + I(Age.ct^3) +
  I(Age.ct^4) + Bonus + Density + Gender + Insurancescore
sev_formula_m2 <- update(sev_formula_m1, . ~ . - Gender)

# 频率公式同理。注意 GroupOne(车辆组别)出现在这里,而未出现在严重程度公式中,
# 因为它只是频率模型所用的定价因子。
freq_formula_m1 <- Numtppd ~ Age.ct + log(Age.ct) + I(Age.ct^2) + I(Age.ct^3) +
  I(Age.ct^4) + Bonus + Density + GroupOne + Insurancescore + Gender
freq_formula_m2 <- update(freq_formula_m1, . ~ . - Gender)

# 严重程度(Gamma)模型:1 = M0(含 Gender),2 = MU(移除 Gender,原始数据),
# 3 = MDP(移除 Gender,全部预测变量去偏),4 = MCDP(移除 Gender,仅
# InsuranceScore 去偏)。同一公式、不同的输入数据,正是区分这四种模型设计的关键所在。
SevGamma1  <- fit_gamma_model(sev_formula_m1, ClaimsData_rd)
SevGamma2  <- fit_gamma_model(sev_formula_m2, ClaimsData_rd)
SevGamma3  <- fit_gamma_model(sev_formula_m2, ClaimsData_M3_rd)
SevGamma4  <- fit_gamma_model(sev_formula_m2, ClaimsData_M4_rd)

# 频率(Poisson)模型,与上文相同的四种设计模式。
FreqPoisson1 <- fit_poisson_model(freq_formula_m1, ClaimsData)
FreqPoisson2 <- fit_poisson_model(freq_formula_m2, ClaimsData)
FreqPoisson3 <- fit_poisson_model(freq_formula_m2, ClaimsData_M3)
FreqPoisson4 <- fit_poisson_model(freq_formula_m2, ClaimsData_M4)
拟合 XGBoost 模型 
# 构建 XGBoost 所需的数值设计矩阵,一份基于原始数据,一份基于完全去偏(MDP)后的
# 数据,再将去偏后的 InsuranceScore 列拼接进原始设计的副本中,得到 MCDP 设计
# (与上文 GLM 部分的逻辑一致)。
xgbData    <- make_xgb_design(ClaimsData)
xgbData_M3 <- make_xgb_design(ClaimsData_DIremv)
xgbData_M4 <- xgbData
m4_train_vars <- intersect(names(xgbData_M4), non_legitimate)
xgbData_M4[, m4_train_vars] <- xgbData_M3[, m4_train_vars]

# 每个频率/严重程度 DMatrix 都必须删除的列:结果变量本身(Numtppd、Indtppd),
# 以及作为偏移量单独使用的风险敞口列(Exppdays)。
drop_common <- c("Exppdays","Numtppd","Indtppd")

# 每种模型设计对应一个理赔频率(计数目标 Numtppd)的 DMatrix。
# FM1 保留 Gender(M0);FM2/FM3/FM4 删除 GenderFemale(MU/MDP/MCDP),
# 三者的区别仅在于所基于的底层数据(原始 vs. 去偏)不同。
xgbData_FM1 <- make_xgb_dmatrix(xgbData, "Numtppd", xgbData$Exppdays, drop_common)
xgbData_FM2 <- make_xgb_dmatrix(xgbData, "Numtppd", xgbData$Exppdays, c(drop_common,"GenderFemale"))
xgbData_FM3 <- make_xgb_dmatrix(xgbData_M3,"Numtppd",xgbData_M3$Exppdays,c(drop_common,"GenderFemale"))
xgbData_FM4 <- make_xgb_dmatrix(xgbData_M4,"Numtppd",xgbData_M4$Exppdays,c(drop_common,"GenderFemale"))

# 频率模型的 XGBoost 超参数。count:poisson 呼应 Poisson GLM 对理赔计数所做的分布假设;
# max_depth/eta/subsample 控制每棵树集成的复杂度与学习速度(刻意设置得较浅,以避免过拟合)。
paramsFreq <- list(objective="count:poisson", eval_metric="poisson-nloglik",
  max_depth=2, eta=0.05, min_child_weight=3, subsample=0.8, colsample_bytree=0.8, tree_method="hist")

set.seed(358)  # 固定 XGBoost 内部的随机性(行/列子抽样),以保证结果可复现
xgbFreq1 <- xgb.train(xgbData_FM1, nrounds=3958, params=paramsFreq)
xgbFreq2 <- xgb.train(xgbData_FM2, nrounds=3988, params=paramsFreq)
xgbFreq3 <- xgb.train(xgbData_FM3, nrounds=3151, params=paramsFreq)
xgbFreq4 <- xgb.train(xgbData_FM4, nrounds=3987, params=paramsFreq)

# 理赔严重程度(每次理赔的成本)同理,基于仅含理赔记录的行(Indtppd > 0)拟合。
xgbData_sev    <- xgbData    %>% filter(Indtppd > 0)
xgbData_M3_sev <- xgbData_M3 %>% filter(Indtppd > 0)
xgbData_M4_sev <- xgbData_M4 %>% filter(Indtppd > 0)

xgbData_SM1 <- make_xgb_dmatrix(xgbData_sev,   "Indtppd", xgbData_sev$Numtppd,   drop_common)
xgbData_SM2 <- make_xgb_dmatrix(xgbData_sev,   "Indtppd", xgbData_sev$Numtppd,   c(drop_common,"GenderFemale"))
xgbData_SM3 <- make_xgb_dmatrix(xgbData_M3_sev,"Indtppd", xgbData_M3_sev$Numtppd,c(drop_common,"GenderFemale"))
xgbData_SM4 <- make_xgb_dmatrix(xgbData_M4_sev,"Indtppd", xgbData_M4_sev$Numtppd,c(drop_common,"GenderFemale"))

# reg:gamma 呼应 Gamma GLM 对理赔严重程度所做的分布假设(恒为正、右偏的成本数据)。
paramsSev <- list(objective="reg:gamma", max_depth=1, eta=0.015,
  min_child_weight=2, subsample=0.8, colsample_bytree=0.8, tree_method="hist")

set.seed(946)
xgbSev1 <- xgb.train(xgbData_SM1, nrounds=2239, params=paramsSev)
xgbSev2 <- xgb.train(xgbData_SM2, nrounds=2113, params=paramsSev)
xgbSev3 <- xgb.train(xgbData_SM3, nrounds=2333, params=paramsSev)
xgbSev4 <- xgb.train(xgbData_SM4, nrounds=1908, params=paramsSev)

MC:针对 CPV(控制受保护变量)的后处理

模型5(MC)无需任何新的训练。从 M0(模型1)出发,在评分时对性别取平均 (Lindholm 等 2022年):

\hat{Y}_{MC} = \frac{1}{2}\left[\hat{f}_{M0}(X_{NP}, X_P = \text{女性}) + \hat{f}_{M0}(X_{NP}, X_P = \text{男性})\right]

对每一位保单持有人,我们各评分两次,一次保持性别不变,一次将性别翻转,然后取平均。

纯保费预测

GLM 与 XGBoost 纯保费预测 
Dataset_import <- ClaimsData
Dataset_M3_pred <- ClaimsData_M3
Dataset_M4_pred <- ClaimsData_M4

## --- GLM 预测 -------------------------------------------------------

# 四种 GLM 设计各自的理赔严重程度(S)预测,用各设计所拟合的模型为每一位保单持有人
# 评分。type="response" 返回原始(金额)尺度上的预测值,而非模型内部所用的对数尺度。
sev_pred <- tibble(
  S1 = predict(SevGamma1, newdata=Dataset_import,  type="response"),
  S2 = predict(SevGamma2, newdata=Dataset_import,  type="response"),
  S3 = predict(SevGamma3, newdata=Dataset_M3_pred, type="response"),
  S4 = predict(SevGamma4, newdata=Dataset_M4_pred, type="response")
)

# 预测理赔频率(F),即每日预期理赔次数,因此需要除去 Poisson 模型拟合时
# 所用的风险敞口偏移量,得到每位保单持有人的理赔率。
freq_pred <- tibble(
  F1 = predict(FreqPoisson1, newdata=Dataset_import,  type="response") / Dataset_import$Exppdays,
  F2 = predict(FreqPoisson2, newdata=Dataset_import,  type="response") / Dataset_import$Exppdays,
  F3 = predict(FreqPoisson3, newdata=Dataset_M3_pred, type="response") / Dataset_import$Exppdays,
  F4 = predict(FreqPoisson4, newdata=Dataset_M4_pred, type="response") / Dataset_import$Exppdays
)

# 模型5(MC)无需单独拟合:直接复用 M0 的系数,并对每一位保单持有人的预测结果
# 在两种性别上取平均。gender_coef_* 是 M0 在对数尺度上的 Gender 系数,
# exp(coef) 将"Gender 对预测值的影响幅度"从对数尺度还原为乘法因子,
# 作用于理赔严重程度/频率之上。
gender_coef_sev  <- coef(SevGamma1)["GenderFemale"]
gender_coef_freq <- coef(FreqPoisson1)["GenderFemale"]

# 对每一位保单持有人,计算"若此人为女性,M0 会如何预测"以及"若此人为男性,
# M0 会如何预测":该保单持有人在 M0 下的实际预测值保持不变,而另一性别下的
# 预测值,则通过施加(或撤销)Gender 系数得到。S5/F5 即为二者的平均值,
# 也就是第二章 MC 公式的具体实现。
S_if_female <- ifelse(Dataset_import$Female==1, sev_pred$S1, sev_pred$S1 * exp(gender_coef_sev))
S_if_male   <- ifelse(Dataset_import$Female==0, sev_pred$S1, sev_pred$S1 * exp(-gender_coef_sev))
S5 <- (S_if_female + S_if_male) / 2

F_if_female <- ifelse(Dataset_import$Female==1, freq_pred$F1, freq_pred$F1 * exp(gender_coef_freq))
F_if_male   <- ifelse(Dataset_import$Female==0, freq_pred$F1, freq_pred$F1 * exp(-gender_coef_freq))
F5 <- (F_if_female + F_if_male) / 2

# 纯保费 = 频率 x 严重程度 x 365(将每日频率率年化为年度预期理赔次数)。
# 模型3-5 标注为"_raw",因为它们仍需经过下文的组合层面重新缩放。
raw_prem <- tibble(
  PurePrem1     = sev_pred$S1 * freq_pred$F1 * 365,
  PurePrem2     = sev_pred$S2 * freq_pred$F2 * 365,
  PurePrem3_raw = sev_pred$S3 * freq_pred$F3 * 365,
  PurePrem4_raw = sev_pred$S4 * freq_pred$F4 * 365,
  PurePrem5_raw = S5 * F5 * 365
)

# adjust_to_base_portfolio() 将模型3-5 重新缩放,使其组合总额与模型2(MU)的
# 总额一致,从而将"投资组合*内部*保费如何重新分配"与"整体业务规模的差异"区分开来。
glmpred_sum <- Dataset_import %>%
  bind_cols(raw_prem) %>%
  mutate(
    PurePrem3 = adjust_to_base_portfolio(PurePrem3_raw, PurePrem2),
    PurePrem4 = adjust_to_base_portfolio(PurePrem4_raw, PurePrem2),
    PurePrem5 = adjust_to_base_portfolio(PurePrem5_raw, PurePrem2),
    realclaim = Indtppd / Exppdays * 365   # 实际年化理赔成本,供后文的准确性指标使用
  )

PurePrem1 <- glmpred_sum$PurePrem1; PurePrem2 <- glmpred_sum$PurePrem2
PurePrem3 <- glmpred_sum$PurePrem3; PurePrem4 <- glmpred_sum$PurePrem4
PurePrem5 <- glmpred_sum$PurePrem5

## --- XGBoost 预测 ---------------------------------------------------

# 构建用于评分的数值设计矩阵:一次基于原始数据,一次基于去偏(M3/MDP)数据。
# align_xgb_design() 确保两者都拥有各自模型训练时所用的完整列集合。
xgb_pred         <- make_xgb_design(Dataset_import)
xgb_pred         <- align_xgb_design(xgb_pred, xgbData)
xgb_pred_debiased <- make_xgb_design(Dataset_M3_pred)
xgb_pred_debiased <- align_xgb_design(xgb_pred_debiased, xgbData_M3)

# MDP 评分数据:从原始设计出发,拼接进每一个合法与非合法列的去偏版本
# (与上文的 ClaimsData_M3 逻辑一致)。
xgb_pred_M3 <- xgb_pred
m3_vars <- intersect(c("Age.ct","Value","Density","Insurancescore",
  grep("^GroupOne", names(xgb_pred_M3), value=TRUE),
  grep("^Bonus",    names(xgb_pred_M3), value=TRUE)), names(xgb_pred_M3))
xgb_pred_M3[, m3_vars] <- xgb_pred_debiased[, m3_vars]
xgb_pred_M3 <- align_xgb_design(xgb_pred_M3, xgbData_M3)

# MCDP 评分数据:同样的思路,但仅拼接去偏后的 InsuranceScore 列。
xgb_pred_M4 <- xgb_pred
m4_vars <- intersect(names(xgb_pred_M4), non_legitimate)
xgb_pred_M4[, m4_vars] <- xgb_pred_M3[, m4_vars]
xgb_pred_M4 <- align_xgb_design(xgb_pred_M4, xgbData_M4)

# MC(模型5)评分数据:为每一位保单持有人构建一份 Gender 翻转后的副本,
# 以便"以相反性别"再评分一次,并与原始预测取平均——这是 XGBoost 版本的
# gender_coef_* 技巧,对应上文 GLM 部分的做法。
xgb_pred_rev <- xgb_pred
xgb_pred_rev$GenderFemale <- 1 - xgb_pred_rev$GenderFemale

# 频率 DMatrix,每种模型设计各一个(外加第5个,用于 Gender 翻转后的评分数据)。
xgbClaimsData_Freq1 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgb_pred$Exppdays,    drop_vars=drop_common)
xgbClaimsData_Freq2 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgb_pred$Exppdays,    drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Freq3 <- make_xgb_dmatrix(xgb_pred_M3,  base_margin=xgb_pred_M3$Exppdays, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Freq4 <- make_xgb_dmatrix(xgb_pred_M4,  base_margin=xgb_pred_M4$Exppdays, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Freq5 <- make_xgb_dmatrix(xgb_pred_rev, base_margin=xgb_pred_rev$Exppdays,drop_vars=drop_common)

# 预测理赔频率,与 GLM 部分相同,除去风险敞口偏移量并年化。
# Freq5 复用模型1(M0),但在 Gender 翻转后的设计上对其评分。
xgbFreq1_pred <- predict(xgbFreq1, xgbClaimsData_Freq1) / xgb_pred$Exppdays * 365
xgbFreq2_pred <- predict(xgbFreq2, xgbClaimsData_Freq2) / xgb_pred$Exppdays * 365
xgbFreq3_pred <- predict(xgbFreq3, xgbClaimsData_Freq3) / xgb_pred_M3$Exppdays * 365
xgbFreq4_pred <- predict(xgbFreq4, xgbClaimsData_Freq4) / xgb_pred_M4$Exppdays * 365
xgbFreq5_pred <- predict(xgbFreq1, xgbClaimsData_Freq5) / xgb_pred_rev$Exppdays * 365

# 严重程度 DMatrix:此处的 base_margin 是每位保单持有人的预测频率,因此严重程度
# 是以该保单持有人预期理赔的频繁程度为条件建模的。
xgbClaimsData_Sev1 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgbFreq1_pred, drop_vars=drop_common)
xgbClaimsData_Sev2 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgbFreq2_pred, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Sev3 <- make_xgb_dmatrix(xgb_pred_M3,  base_margin=xgbFreq3_pred, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Sev4 <- make_xgb_dmatrix(xgb_pred_M4,  base_margin=xgbFreq4_pred, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Sev5 <- make_xgb_dmatrix(xgb_pred_rev, base_margin=xgbFreq5_pred, drop_vars=drop_common)

# 严重程度模型直接输出纯保费(严重程度已通过上文的 base_margin 与频率相结合),
# 因此此处无需再单独进行乘法运算。模型5(MC)对 M0 严重程度模型在原始设计与
# Gender 翻转设计上的预测取平均,平均思路与上文 GLM 的 S5/F5 相同。
xgbPrem1_raw <- predict(xgbSev1, xgbClaimsData_Sev1)
xgbPrem2_raw <- predict(xgbSev2, xgbClaimsData_Sev2)
xgbPrem3_raw <- predict(xgbSev3, xgbClaimsData_Sev3)
xgbPrem4_raw <- predict(xgbSev4, xgbClaimsData_Sev4)
xgbPrem5_raw <- 0.5 * (predict(xgbSev1, xgbClaimsData_Sev1) + predict(xgbSev1, xgbClaimsData_Sev5))

# 将每个 XGBoost 模型的组合总额重新缩放至与 GLM MU 的总额(PurePrem2)一致,
# 以便在相同的整体业务规模下比较 GLM 与 XGBoost 模型。
xgbpred_sum <- Dataset_import %>%
  mutate(
    xgbPurePrem1 = xgbPrem1_raw / sum(xgbPrem1_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem2 = xgbPrem2_raw / sum(xgbPrem2_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem3 = xgbPrem3_raw / sum(xgbPrem3_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem4 = xgbPrem4_raw / sum(xgbPrem4_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem5 = xgbPrem5_raw / sum(xgbPrem5_raw) * sum(glmpred_sum$PurePrem2),
    realclaim = Indtppd / Exppdays * 365
  )

组合层面的调整

GLM 模型3–5以及所有 XGBoost 模型都被按比例缩放,使其预测保费总额与 GLM MU(模型2)的组合总额(即全部100,000份保单的预测保费之和,代表保险公司的完整业务组合)相匹配。这样一来,比较的重点便落在保费的重新分配上,而非组合层面的总体差异。

公平性指标

差异性影响比率(DIR,公平性):受保护群体间平均保费的比率。

\text{差异性影响比率} = \frac{\mathbb{E}(\hat{Y} \mid X_P = b)}{\mathbb{E}(\hat{Y} \mid X_P = a)}

  • 数值越接近1,表示各群体间平均保费越相近。
  • 保险行业的五分之四原则:期望该比率落在0.8至1.25之间。
  • 这正是我们在此检验人口统计学均等性的方式,即预测结果在受保护群体间平均而言不应存在差异这一理念。

RMSE(准确性):衡量与实际理赔的偏离程度。数值越小越好。

案例研究:审前风险评估(COMPAS)

设想美国某县的刑事法院系统正在决定是否续签一份审前风险评估工具的合同,该工具用于协助法官设定保释与释放条件。这一工具已使用多年,被认为有效减少了不必要的审前羁押,但一项近期的独立审计(呼应了针对真实 COMPAS 工具的 ProPublica 调查报道 (Angwin 等 2016年))发现,该工具将不会再犯的黑人被告标记为高风险的比例,远高于将不会再犯的白人被告标记为高风险的比例。民权倡导者主张应当废除该工具;供应商与部分法官则认为,该工具仍优于不加结构的人工判断,废除它只会让该县回到一个同样未必更公平、只是更不一致的现状。在合同续签表决之前,该县的首席公设辩护人被要求对该工具进行独立评估:它是否满足一项能够在法律挑战下站得住脚的公平性准则?如果不满足,是否可以在不使其失去实用价值的前提下加以修正?

本章此前的内容全部是回归问题:预测一个连续的价格。而这一决策不同,它是二元的:释放或羁押、标记或放行。第二章中的 M0/MU 模型设计框架原封不动地适用于此。改变的只是模型类型和公平性指标。

我们使用真实的 COMPAS 再犯风险数据集(再犯是指出狱后因新罪行而被逮捕)来评估这一情境,由我们自己拟合模型,并使用 fairness R 包 (Kozodoi 和 V. Varga 2021年),直接根据群体标签和预测概率计算标准的分类公平性指标。

提示

定价案例研究中的同一套工作流程在此同样适用:确定准则 → 选择干预阶段 → 拟合 → 衡量权衡取舍 → 审视受影响对象。改变的只是结果变量(一个二元决策,而非价格)和公平性指标。

COMPAS:结果

使用 fairness 包计算公平性指标

我们针对 M0 和 MU,分别计算第二章分类体系中的三项群体公平性检验。每一项都使用 fairness 包中的一个特定函数,而每个函数具体计算的是哪一个统计量,这一点至关重要:

  • 人口统计学均等性(\hat{Y} \perp X_P):使用 prop_parity(),该函数比较各群体被正向分类的比例。(dem_parity() 比较的则是原始计数,由于两个群体规模差异很大(2,103 对 3,175),这会造成失真,因此对这一准则而言并非正确的函数。)
  • 对分离性的部分检验:equal_odds() 仅计算群体的敏感度(真阳性率)。这更接近于机会均等,而非要求真阳性率和假阳性率同时均等的完整均衡赔率。我们在下文手动计算并直接报告 FPR 和 FNR,以呈现更完整的图景。
  • 对充分性的部分检验:pred_rate_parity() 仅比较精确率(阳性预测值),这只是完整充分性条件 Y \perp X_P \mid \hat{Y} 的一个方向,该条件同时还要求阴性预测值相等。

无意识几乎没有改变任何东西。MU 几乎不损失任何准确率(66.5% 对比 66.8%),但无论模型是否直接看到族裔变量,每一项差异比率都几乎原封不动地保留了下来。一名不会再犯的非裔美国被告,被标记为高风险的概率,大约是一名不会再犯的白人被告的两倍(FPR 差距:MU 下为33.0% 对比17.2%)。这与 ProPublica 针对实际 COMPAS 工具所报告的发现在性质上完全一致 (Angwin 等 2016年),而在这里,仅使用四个通用预测变量的一个简单逻辑回归模型,便复现了这一结果。

重要

人口统计学均等性显示出最大的差距(比率≈2),TPR/机会均等差距为中等程度(比率≈1.7),而精确率差距则相对较小(比率≈1.1)。 这并非三个独立的发现——而是同一个发现在不同统计量视角下的呈现。人口统计学均等性完全忽略真实结果,因此除了模型本身的不公平之外,它还完全反映了基础再犯率之间的潜在差距(39.1% 对比52.3%)。精确率则以预测结果为条件,因而部分吸收了同样的基准率差距。第二章“分离性与充分性”专栏已经指出,当基准率不同时,分离性与充分性通常无法同时满足,完美预测等特殊情形除外。这正是那一不可能性结论在真实数据上的体现,而非纯理论上的趣味结果。选择一项准则,就是在选择基准率差异中有多少应被计入“不公平”,又有多少应被视为“信号”。

在拟合之前对预测变量应用 MDP 或 MCDP 式的去偏处理(与上文定价案例研究中的做法完全一致),会使这些比率更接近1,但同时也会带来一定的准确性代价。这与上文已经探讨过的权衡取舍完全相同,只是这里以分类差异比率而非保费的差异性影响比率来衡量。

COMPAS:后处理修正

实现某一准则:使用 roc_pivot() 进行后处理

fairness 包只能衡量差异,不提供修正方法。fairmodels(上文已用于保险差异性影响消除器)也提供了后处理功能。roc_pivot() 实现了一种拒绝选项修正 (Kamiran 等 2012年),它对落在决策分界值附近、宽度为 theta 的区间内的预测结果重新贴标签,给予处于弱势群体的边界个案以有利推定,同时将处于优势群体的边界个案推向相反方向。

从机制上看,这相当于以分界值为中心做镜像翻转:边界概率 p 变为 2 \times \text{分界值} - p。原本刚好被预测为有利结果的优势群体个案,会被翻转为不利结果;原本刚好被预测为不利结果的弱势群体个案,会被翻转为有利结果。区间之外、模型有把握的预测则保持不变。

roc_pivot() 假定高于分界值的概率代表有利结果,且 privileged 参数所指定的是优势群体。在我们的模型中,高于0.5的概率意味着预测再犯,即不利结果,因此在调用 roc_pivot() 之前,我们先将模型转换为预测不再犯这一有利结果,并保持白人(现状模型所偏向的群体)为优势群体。这样一来,函数各参数的含义便与其名称所表达的一致,而不必依赖两次相互抵消的方向反转来得到正确的结果。

# predict_function 打包在一起,使 roc_pivot() 看到的是不再犯的概率。
mu_explainer <- DALEX::explain(
  mu, data = compas_data, y = y_favourable,
  predict_function = predict_non_recidivism, verbose = FALSE
)

# 真正执行后处理修正的一行:对落在0.5分界值附近、宽度为 theta 的区间内的预测
# 重新贴标签,将边界个案推向有利于非优势群体的结果。用不同的 theta 值重新运行
# 这一行,即可复现下方表格中的结果。
mu_fixed <- roc_pivot(mu_explainer, protected = compas_data$ethnicity,
                       privileged = "Caucasian", cutoff = 0.5, theta = 0.05)

# roc_pivot 返回的是经调整后的不再犯概率;
# 转换回再犯概率,以便下游代码保持原有的记法约定。
compas_data$prob_MU_fixed <- 1 - mu_fixed$y_hat

0(MU,未修正) 66.5% 1.94 1.67 1.15
0.05 65.7% 1.13 1.11 1.31
0.10 62.8% 0.63 0.69 1.45

0.20 56.8% 0.23 0.30 1.73

解读这一权衡取舍

在 theta = 0.05 时,以有限的准确性代价(66.5% → 65.7%)换来了人口统计学均等性的大幅改善(1.94 → 1.13),并使 TPR 差距几乎恰好达到均等(1.67 → 1.11)。这看起来像是天上掉馅饼,直到我们同时读一下预测率均等性这一列。

重要

随着修正力度增强,预测率均等性单调地变得更差,theta 从0增至0.20时,该指标从1.15(勉强违反)升至1.73(严重违反)。将人口统计学均等性和 TPR 差距推向1,并不会让精确率差距保持不变——反而会主动使其扩大。超过 theta ≈ 0.10 之后,人口统计学均等性和 TPR 差距会下冲到1以下,这意味着此时的修正已经将差异反转,而非消除,同时准确性代价陡增(66.5% → 56.8%,几乎不比抛硬币好多少)。

这正是第二章的不可能性结论,以一个可调“旋钮”、而非单一的前后对比快照的形式呈现出来。不存在能够同时满足这三项检验的 theta 值,因为只要这两个群体的基础再犯率存在差异,这样的值就根本不存在。后处理让你可以选择落在这条曲线上的哪个位置,但无法让你逃离这条曲线本身。

小结

  • 全部四种反歧视模型设计,均可在真实保险数据上以有限的准确性代价加以实现,而同样的工作流程(确定准则 → 选择阶段 → 拟合 → 衡量权衡取舍 → 审视重新分配)也可迁移至其他领域,包括上文的二元分类(COMPAS)场景。
  • 模型的选择应当遵从第二章中所选定的监管准则,而非建模上的便利性。
  • MDP 带来最强的群体公平性,但也带来最大幅度的结果重新分配。MCDP 则更具针对性。
  • 无意识(MU)本身很少足够。COMPAS 案例研究表明,即便在完全脱离保险业的二元分类场景下,这一结论依然成立。
  • 后处理可以将一个分类器推向任意一项群体公平性检验的达标,但无法同时满足全部三项。在 COMPAS 实例中,将 TPR 差距和人口统计学均等性推向均等,反而主动恶化了预测率均等性。选择一种修正方法,与第二章第一步中选择一项准则,是密不可分的。

## 从原则到实践

第二章介绍了*选择哪一种*公平性准则,以及*哪一种*模型设计(M0、MU、MDP、MCDP、MC)能够落实该准则。将这一选择转化为一个可运行的系统,无论在哪个领域,都遵循相同的步骤:

1. **确定准则以及该准则所适用的结果变量**(第二章,第一步)。
2. **选择干预阶段**(预处理、处理中或后处理)以及相应的模型设计(第二章,第二步)。
3. **实现并拟合**模型,保留一个基准模型(M0)用于比较。
4. **衡量权衡取舍**:将一项公平性指标(如差异性影响比率)与一项准确性指标(如 RMSE)对照评估,而非孤立看待。
5. **审视重新分配**:相对于当前基准,哪些子群体获益,哪些子群体受损。
6. **对逆向选择进行压力测试**(选读深度):检验更公平的模型是否在某个实际结果偏向其中一个模型的细分市场上,与基准模型系统性地不一致。有关这一步骤的双升力图(double-lift-chart)实例分析,请参见 [fair.feihuang.org 的案例研究:公平模型](https://fair.feihuang.org/Case%20Study%202/case_study2.html)。

## 为什么将 InsuranceScore 作为非合法变量?

@xin2024antidiscrimination 中的基准情形,将 `InsuranceScore` 视为唯一的非合法变量。它代表了一类富含代理信息的因子(如基于信用记录的保险评分),这类因子:

- 对理赔风险仍保留一定的预测价值
- 可能与受保护属性(性别)相关
- 在某些监管制度下会受到更严格的公平性审查

这一构造方式也具有实际用途。差异性影响消除器要求连续型输入变量,因此将分类型代理变量汇总为单一评分,使得在 MCDP 下进行去偏处理成为可能。

# 预处理

## 使用差异性影响消除器去偏

对于 MDP(模型3)和 MCDP(模型4),我们使用 `fairmodels` R 包中实现的**差异性影响消除器** [@feldman2015certifying] 对预测变量进行预处理。

该消除器调整连续变量的分布,使其不再依赖于受保护属性(性别),同时保留总体分布形态。

- **MDP**:应用于所有选定的预测变量(年龄、无赔款折扣等级、价值、密度、GroupOne、InsuranceScore)
- **MCDP**:仅应用于非合法变量(InsuranceScore)

在去偏之前,会向有序变量添加少量随机噪声,以避免出现取值相同的问题。去偏之后,有序变量会被重新映射回其原始的因子水平。

```{r}
#| code-fold: true
#| code-summary: "展示情形设定与辅助函数定义"

# InsuranceScore 是唯一被视为"非合法"(代理变量)的预测变量;
# glm_predictors 中其余变量均视为合法。这一区分正是 MDP(全部去偏)
# 与 MCDP(仅对 non_legitimate 去偏)的差异所在。
non_legitimate <- c("Insurancescore")

glm_predictors <- c("Age.ct", "Bonus", "Value", "Density", "GroupOne", "Insurancescore")
xgb_predictors <- glm_predictors

# 将连续的 Age(以年为单位)转换为 "18-22"、"23-27" 等年龄段标签。
# 之所以需要这一步,是因为下文的去偏步骤将 Age 当作连续变量处理,
# 而 GLM 使用的是分类(分段)版本的 Age,因此去偏后需要重新分段。
make_age_group <- function(age) {
  cut(age,
    breaks = c(-Inf, 22, 27, 32, 37, 42, 47, 52, 57, 62, 67, Inf),
    labels = c("18-22","23-27","28-32","33-37","38-42","43-47","48-52","53-57","58-62","63-67","68+"),
    right = TRUE)
}

# 将一个连续(去偏后)的变量四舍五入回最接近的原始整数水平,并裁剪到
# [min_level, max_level] 范围内。用于将 Bonus 与 GroupOne 从去偏步骤中的
# 连续处理方式,还原为它们原本的离散类别。
bin_to_factor <- function(x, min_level, max_level) {
  levels <- min_level:max_level
  x <- pmin(pmax(x, min_level), max_level)        # 裁剪:不低于 min_level,不高于 max_level
  cuts <- c(min_level - 0.5, levels[-1] - 0.5, max_level + 0.5)
  as.factor(as.numeric(cut(x, breaks = cuts, labels = levels, include.lowest = TRUE)))
}

# 构建 data 的去偏版本:对 features_to_transform 中指定的列(MDP 对应全部预测变量,
# MCDP 仅对应 InsuranceScore)运行 disparate_impact_remover(),使其分布不再依赖于 Gender。
make_di_removed_data <- function(data, features_to_transform, lambda = 1) {
  data_for_di <- data %>%
    # disparate_impact_remover() 需要连续型输入,因此这里将当前为分类变量的
    # Bonus 与 GroupOne 临时转换为数值型。
    mutate(GroupOne.ct = as.numeric(GroupOne), Bonus.ct = as.numeric(Bonus))

  # 添加微小随机噪声(jitter)以打破重复取值之间的并列关系,这是去偏算法
  # 对观测值排序所需要的。每个变量的最小值与最大值保持不变(keep),
  # 以保证取值范围不发生改变。
  jitter_keep_minmax <- function(x, factor = 1) {
    keep <- x == min(x, na.rm=TRUE) | x == max(x, na.rm=TRUE)
    x[!keep] <- jitter(x[!keep], factor = factor)
    x
  }

  # 对下文将要去偏的每一个变量,应用 jitter_keep_minmax()。GroupOne.ct 使用了
  # 更大的 factor(5),因为它是一个粗粒度的整数编码,并列取值比其他变量多得多,
  # 因此需要更强的噪声才能打破这些并列关系。
  data_for_di <- data_for_di %>%
    mutate(
      Age.ct = jitter_keep_minmax(Age.ct, factor=1),
      Bonus.ct = jitter_keep_minmax(Bonus.ct, factor=1),
      Value = jitter_keep_minmax(Value, factor=1),
      Density = jitter_keep_minmax(Density, factor=1),
      GroupOne.ct = jitter_keep_minmax(GroupOne.ct, factor=5),
      Insurancescore = jitter_keep_minmax(Insurancescore, factor=1)
    )

  # 真正执行去偏的一步:调整 features_to_transform 中每一列的分布,使其对每个
  # Gender 群体而言都相同。lambda = 1 表示施加完全修正(lambda = 0 则保持数据不变)。
  di_data <- disparate_impact_remover(
    data = data_for_di, protected = as.factor(data_for_di$Gender),
    features_to_transform = features_to_transform, lambda = lambda
  )

  # 将 Age、GroupOne、Bonus 从去偏后的连续取值,转换回 GLM 所需要的分类分段,
  # 使用上文定义的两个辅助函数。
  di_data <- di_data %>%
    mutate(
      Age = make_age_group(Age.ct),
      Age = as.factor(as.numeric(Age)),
      GroupOne = bin_to_factor(GroupOne.ct, 1, 20),
      Bonus = bin_to_factor(Bonus.ct, 1, 21)
    )
  di_data
}

# glm() 的简单封装,固定了频率—严重程度框架中每一部分所用的分布族:
# 理赔严重程度(成本,恒为正,右偏)用 Gamma;理赔频率(计数)用 Poisson。
# 封装后无需在下文四种模型设计对应的八次 glm() 调用中,每次都重复 family=... 参数。
fit_gamma_model  <- function(formula, data) glm(formula, family=Gamma(link="log"), data=data)
fit_poisson_model <- function(formula, data) glm(formula, family=poisson(link="log"), data=data, offset=log(Exppdays))

# 将一组原始预测保费按比例缩放,使其总额与某个参考组合的总额一致
# (用于下文,使各模型的整体业务规模具有可比性,差异仅体现在保费在保单持有人之间的*分布*上)。
adjust_to_base_portfolio <- function(raw_premium, base_premium) raw_premium * sum(base_premium) / sum(raw_premium)

# XGBoost 需要数值矩阵,而非包含因子的数据框,因此这里将每个分类预测变量
# 转换为 0/1 哑变量列(model.matrix()),并删除 XGBoost 不需要的列
# (即结果变量,以及冗余的参照水平列 GenderMale)。
make_xgb_design <- function(data) {
  # 以下每一项被剔除的原因各不相同,并非因为 XGBoost 无法处理它们:
  # - "Age":年龄的分段/分类版本。模型实际使用的是连续版本 Age.ct(予以保留),
  #   因此 Age 只是重复了同一信息。
  # - "GroupOne.ct" 与 "Bonus.ct":GroupOne 与 Bonus 的连续数值版本,是差异性
  #   影响消除器内部计算过程中遗留下来的列(仅存在于去偏后的数据
  #   ClaimsData_DIremv 中)。模型实际使用的是分类版本的 GroupOne 与 Bonus
  #   (予以保留)作为真正的定价因子,因此这两列会与之重复。
  # - "Female":Gender 的0/1重复版本,仅供别处的 MC 性别取平均步骤使用;
  #   下文的 model.matrix() 已经会对 Gender 本身进行独热编码。
  # - "ClaimSeverity":GLM 严重程度模型的结果变量。XGBoost 的严重程度目标
  #   变量用的是 Indtppd,因此 ClaimSeverity 绝不能作为预测变量出现,
  #   否则会将答案泄漏给模型。
  xgb_unused <- c("Age","GroupOne.ct","Bonus.ct","Female","ClaimSeverity")
  data %>%
    select(-any_of(xgb_unused)) %>%
    model.matrix(~ 0 + ., data=.) %>%
    as.data.frame() %>%
    select(-any_of("GenderMale"))
}

# 将预测变量矩阵打包为 XGBoost 训练/预测函数所需要的 xgb.DMatrix 格式。
# base_margin 在对数尺度上提供一个已知的偏移量(例如频率模型的风险敞口,
# 或严重程度模型所用的已拟合频率),这样 XGBoost 只需学习剩余的模式,
# 而无需学习偏移量本身。仅在评分(而非训练)时省略 response。
make_xgb_dmatrix <- function(data, response=NULL, base_margin, drop_vars) {
  x <- data %>% select(-any_of(drop_vars)) %>% as.matrix()
  if (is.null(response)) dmat <- xgb.DMatrix(x)
  else dmat <- xgb.DMatrix(x, label=data[[response]])
  setinfo(dmat, "base_margin", log(base_margin))
  dmat
}

# 确保新数据集拥有与 XGBoost 训练数据完全相同、顺序也一致的哑变量列
# (new_data 中缺失的列填充为0)。之所以需要这一步,是因为如果某个类别
# 恰好只出现在训练数据或评分数据中的一个,model.matrix() 可能会为二者
# 生成略有不同的列。
align_xgb_design <- function(new_data, train_data) {
  missing_cols <- setdiff(names(train_data), names(new_data))
  if (length(missing_cols) > 0) new_data[missing_cols] <- 0
  new_data[, names(train_data), drop=FALSE]
}
```

# 拟合模型

## GLM 频率—严重程度框架

GLM 和 XGBoost 均采用**频率—严重程度**分解:

$$\text{纯保费} = \text{理赔频率} \times \text{理赔严重程度}$$

- **频率**:采用对数链接函数与风险敞口偏移量的 Poisson GLM(风险敞口是指保单处于有效状态、面临理赔风险的天数)
- **严重程度**:采用对数链接函数的 Gamma GLM(仅基于发生理赔的数据拟合)

按照 @schelldorfer2019nesting 的做法,年龄以连续函数形式($\text{Age}, \log(\text{Age}), \text{Age}^2, \text{Age}^3, \text{Age}^4$)纳入模型。

```{r}
#| code-fold: true
#| code-summary: "拟合 GLM 模型"

# sev_formula_m1 是包含 Gender 的严重程度公式(用于 M0);update(..., . ~ . - Gender)
# 在已有公式的基础上移除 Gender,而无需重新输入一遍,由此得到 sev_formula_m2
# (用于不将 Gender 作为直接预测变量的 MU、MDP、MCDP)。
sev_formula_m1 <- ClaimSeverity ~ Age.ct + log(Age.ct) + I(Age.ct^2) + I(Age.ct^3) +
  I(Age.ct^4) + Bonus + Density + Gender + Insurancescore
sev_formula_m2 <- update(sev_formula_m1, . ~ . - Gender)

# 频率公式同理。注意 GroupOne(车辆组别)出现在这里,而未出现在严重程度公式中,
# 因为它只是频率模型所用的定价因子。
freq_formula_m1 <- Numtppd ~ Age.ct + log(Age.ct) + I(Age.ct^2) + I(Age.ct^3) +
  I(Age.ct^4) + Bonus + Density + GroupOne + Insurancescore + Gender
freq_formula_m2 <- update(freq_formula_m1, . ~ . - Gender)

# 严重程度(Gamma)模型:1 = M0(含 Gender),2 = MU(移除 Gender,原始数据),
# 3 = MDP(移除 Gender,全部预测变量去偏),4 = MCDP(移除 Gender,仅
# InsuranceScore 去偏)。同一公式、不同的输入数据,正是区分这四种模型设计的关键所在。
SevGamma1  <- fit_gamma_model(sev_formula_m1, ClaimsData_rd)
SevGamma2  <- fit_gamma_model(sev_formula_m2, ClaimsData_rd)
SevGamma3  <- fit_gamma_model(sev_formula_m2, ClaimsData_M3_rd)
SevGamma4  <- fit_gamma_model(sev_formula_m2, ClaimsData_M4_rd)

# 频率(Poisson)模型,与上文相同的四种设计模式。
FreqPoisson1 <- fit_poisson_model(freq_formula_m1, ClaimsData)
FreqPoisson2 <- fit_poisson_model(freq_formula_m2, ClaimsData)
FreqPoisson3 <- fit_poisson_model(freq_formula_m2, ClaimsData_M3)
FreqPoisson4 <- fit_poisson_model(freq_formula_m2, ClaimsData_M4)
```

```{r}
# 构建 XGBoost 所需的数值设计矩阵,一份基于原始数据,一份基于完全去偏(MDP)后的
# 数据,再将去偏后的 InsuranceScore 列拼接进原始设计的副本中,得到 MCDP 设计

m4_train_vars <- intersect(names(xgbData_M4), non_legitimate)

# 每个频率/严重程度 DMatrix 都必须删除的列:结果变量本身(Numtppd、Indtppd),
# 以及作为偏移量单独使用的风险敞口列(Exppdays)。
drop_common <- c("Exppdays","Numtppd","Indtppd")

# 每种模型设计对应一个理赔频率(计数目标 Numtppd)的 DMatrix。
# FM1 保留 Gender(M0);FM2/FM3/FM4 删除 GenderFemale(MU/MDP/MCDP),
# 三者的区别仅在于所基于的底层数据(原始 vs. 去偏)不同。

xgbData_FM3 <- make_xgb_dmatrix(xgbData_M3,"Numtppd",xgbData_M3$Exppdays,c(drop_common,"GenderFemale"))

# 频率模型的 XGBoost 超参数。count:poisson 呼应 Poisson GLM 对理赔计数所做的分布假设;
# max_depth/eta/subsample 控制每棵树集成的复杂度与学习速度(刻意设置得较浅,以避免过拟合)。
paramsFreq <- list(objective="count:poisson", eval_metric="poisson-nloglik",
  max_depth=2, eta=0.05, min_child_weight=3, subsample=0.8, colsample_bytree=0.8, tree_method="hist")

set.seed(358)  # 固定 XGBoost 内部的随机性(行/列子抽样),以保证结果可复现
xgbFreq1 <- xgb.train(xgbData_FM1, nrounds=3958, params=paramsFreq)
xgbFreq2 <- xgb.train(xgbData_FM2, nrounds=3988, params=paramsFreq)
xgbFreq3 <- xgb.train(xgbData_FM3, nrounds=3151, params=paramsFreq)
xgbFreq4 <- xgb.train(xgbData_FM4, nrounds=3987, params=paramsFreq)

# 理赔严重程度(每次理赔的成本)同理,基于仅含理赔记录的行(Indtppd > 0)拟合。
xgbData_sev    <- xgbData    %>% filter(Indtppd > 0)

xgbData_M4_sev <- xgbData_M4 %>% filter(Indtppd > 0)

xgbData_SM1 <- make_xgb_dmatrix(xgbData_sev,   "Indtppd", xgbData_sev$Numtppd,   drop_common)
xgbData_SM2 <- make_xgb_dmatrix(xgbData_sev,   "Indtppd", xgbData_sev$Numtppd,   c(drop_common,"GenderFemale"))
xgbData_SM3 <- make_xgb_dmatrix(xgbData_M3_sev,"Indtppd", xgbData_M3_sev$Numtppd,c(drop_common,"GenderFemale"))
xgbData_SM4 <- make_xgb_dmatrix(xgbData_M4_sev,"Indtppd", xgbData_M4_sev$Numtppd,c(drop_common,"GenderFemale"))

# reg:gamma 呼应 Gamma GLM 对理赔严重程度所做的分布假设(恒为正、右偏的成本数据)。
paramsSev <- list(objective="reg:gamma", max_depth=1, eta=0.015,
  min_child_weight=2, subsample=0.8, colsample_bytree=0.8, tree_method="hist")

set.seed(946)
xgbSev1 <- xgb.train(xgbData_SM1, nrounds=2239, params=paramsSev)
xgbSev2 <- xgb.train(xgbData_SM2, nrounds=2113, params=paramsSev)
xgbSev3 <- xgb.train(xgbData_SM3, nrounds=2333, params=paramsSev)
xgbSev4 <- xgb.train(xgbData_SM4, nrounds=1908, params=paramsSev)
```

## MC:针对 CPV(控制受保护变量)的后处理

模型5(MC)无需任何新的训练。从 M0(模型1)出发,在评分时对性别取平均 [@lindholm2022discrimination]:

$$\hat{Y}_{MC} = \frac{1}{2}\left[\hat{f}_{M0}(X_{NP}, X_P = \text{女性}) + \hat{f}_{M0}(X_{NP}, X_P = \text{男性})\right]$$

对每一位保单持有人,我们各评分两次,一次保持性别不变,一次将性别翻转,然后取平均。

# 纯保费预测

```{r}
#| code-fold: true
#| code-summary: "GLM 与 XGBoost 纯保费预测"

Dataset_import <- ClaimsData
Dataset_M3_pred <- ClaimsData_M3
Dataset_M4_pred <- ClaimsData_M4

## --- GLM 预测 -------------------------------------------------------

# 四种 GLM 设计各自的理赔严重程度(S)预测,用各设计所拟合的模型为每一位保单持有人
# 评分。type="response" 返回原始(金额)尺度上的预测值,而非模型内部所用的对数尺度。
sev_pred <- tibble(
  S1 = predict(SevGamma1, newdata=Dataset_import,  type="response"),
  S2 = predict(SevGamma2, newdata=Dataset_import,  type="response"),
  S3 = predict(SevGamma3, newdata=Dataset_M3_pred, type="response"),
  S4 = predict(SevGamma4, newdata=Dataset_M4_pred, type="response")
)

# 预测理赔频率(F),即每日预期理赔次数,因此需要除去 Poisson 模型拟合时
# 所用的风险敞口偏移量,得到每位保单持有人的理赔率。
freq_pred <- tibble(
  F1 = predict(FreqPoisson1, newdata=Dataset_import,  type="response") / Dataset_import$Exppdays,
  F2 = predict(FreqPoisson2, newdata=Dataset_import,  type="response") / Dataset_import$Exppdays,
  F3 = predict(FreqPoisson3, newdata=Dataset_M3_pred, type="response") / Dataset_import$Exppdays,
  F4 = predict(FreqPoisson4, newdata=Dataset_M4_pred, type="response") / Dataset_import$Exppdays
)

# 模型5(MC)无需单独拟合:直接复用 M0 的系数,并对每一位保单持有人的预测结果
# 在两种性别上取平均。gender_coef_* 是 M0 在对数尺度上的 Gender 系数,
# exp(coef) 将"Gender 对预测值的影响幅度"从对数尺度还原为乘法因子,
# 作用于理赔严重程度/频率之上。
gender_coef_sev  <- coef(SevGamma1)["GenderFemale"]
gender_coef_freq <- coef(FreqPoisson1)["GenderFemale"]

# 对每一位保单持有人,计算"若此人为女性,M0 会如何预测"以及"若此人为男性,
# M0 会如何预测":该保单持有人在 M0 下的实际预测值保持不变,而另一性别下的
# 预测值,则通过施加(或撤销)Gender 系数得到。S5/F5 即为二者的平均值,
# 也就是第二章 MC 公式的具体实现。
S_if_female <- ifelse(Dataset_import$Female==1, sev_pred$S1, sev_pred$S1 * exp(gender_coef_sev))
S_if_male   <- ifelse(Dataset_import$Female==0, sev_pred$S1, sev_pred$S1 * exp(-gender_coef_sev))
S5 <- (S_if_female + S_if_male) / 2

F_if_female <- ifelse(Dataset_import$Female==1, freq_pred$F1, freq_pred$F1 * exp(gender_coef_freq))
F_if_male   <- ifelse(Dataset_import$Female==0, freq_pred$F1, freq_pred$F1 * exp(-gender_coef_freq))
F5 <- (F_if_female + F_if_male) / 2

# 纯保费 = 频率 x 严重程度 x 365(将每日频率率年化为年度预期理赔次数)。
# 模型3-5 标注为"_raw",因为它们仍需经过下文的组合层面重新缩放。
raw_prem <- tibble(
  PurePrem1     = sev_pred$S1 * freq_pred$F1 * 365,
  PurePrem2     = sev_pred$S2 * freq_pred$F2 * 365,
  PurePrem3_raw = sev_pred$S3 * freq_pred$F3 * 365,
  PurePrem4_raw = sev_pred$S4 * freq_pred$F4 * 365,
  PurePrem5_raw = S5 * F5 * 365
)

# adjust_to_base_portfolio() 将模型3-5 重新缩放,使其组合总额与模型2(MU)的
# 总额一致,从而将"投资组合*内部*保费如何重新分配"与"整体业务规模的差异"区分开来。
glmpred_sum <- Dataset_import %>%
  bind_cols(raw_prem) %>%
  mutate(
    PurePrem3 = adjust_to_base_portfolio(PurePrem3_raw, PurePrem2),
    PurePrem4 = adjust_to_base_portfolio(PurePrem4_raw, PurePrem2),
    PurePrem5 = adjust_to_base_portfolio(PurePrem5_raw, PurePrem2),
    realclaim = Indtppd / Exppdays * 365   # 实际年化理赔成本,供后文的准确性指标使用
  )

PurePrem1 <- glmpred_sum$PurePrem1; PurePrem2 <- glmpred_sum$PurePrem2
PurePrem3 <- glmpred_sum$PurePrem3; PurePrem4 <- glmpred_sum$PurePrem4
PurePrem5 <- glmpred_sum$PurePrem5

## --- XGBoost 预测 ---------------------------------------------------

# 构建用于评分的数值设计矩阵:一次基于原始数据,一次基于去偏(M3/MDP)数据。
# align_xgb_design() 确保两者都拥有各自模型训练时所用的完整列集合。
xgb_pred         <- make_xgb_design(Dataset_import)
xgb_pred         <- align_xgb_design(xgb_pred, xgbData)
xgb_pred_debiased <- make_xgb_design(Dataset_M3_pred)
xgb_pred_debiased <- align_xgb_design(xgb_pred_debiased, xgbData_M3)

# MDP 评分数据:从原始设计出发,拼接进每一个合法与非合法列的去偏版本
# (与上文的 ClaimsData_M3 逻辑一致)。
xgb_pred_M3 <- xgb_pred
m3_vars <- intersect(c("Age.ct","Value","Density","Insurancescore",
  grep("^GroupOne", names(xgb_pred_M3), value=TRUE),
  grep("^Bonus",    names(xgb_pred_M3), value=TRUE)), names(xgb_pred_M3))
xgb_pred_M3[, m3_vars] <- xgb_pred_debiased[, m3_vars]
xgb_pred_M3 <- align_xgb_design(xgb_pred_M3, xgbData_M3)

# MCDP 评分数据:同样的思路,但仅拼接去偏后的 InsuranceScore 列。
xgb_pred_M4 <- xgb_pred
m4_vars <- intersect(names(xgb_pred_M4), non_legitimate)
xgb_pred_M4[, m4_vars] <- xgb_pred_M3[, m4_vars]
xgb_pred_M4 <- align_xgb_design(xgb_pred_M4, xgbData_M4)

# MC(模型5)评分数据:为每一位保单持有人构建一份 Gender 翻转后的副本,
# 以便"以相反性别"再评分一次,并与原始预测取平均——这是 XGBoost 版本的
# gender_coef_* 技巧,对应上文 GLM 部分的做法。
xgb_pred_rev <- xgb_pred
xgb_pred_rev$GenderFemale <- 1 - xgb_pred_rev$GenderFemale

# 频率 DMatrix,每种模型设计各一个(外加第5个,用于 Gender 翻转后的评分数据)。
xgbClaimsData_Freq1 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgb_pred$Exppdays,    drop_vars=drop_common)
xgbClaimsData_Freq2 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgb_pred$Exppdays,    drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Freq3 <- make_xgb_dmatrix(xgb_pred_M3,  base_margin=xgb_pred_M3$Exppdays, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Freq4 <- make_xgb_dmatrix(xgb_pred_M4,  base_margin=xgb_pred_M4$Exppdays, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Freq5 <- make_xgb_dmatrix(xgb_pred_rev, base_margin=xgb_pred_rev$Exppdays,drop_vars=drop_common)

# 预测理赔频率,与 GLM 部分相同,除去风险敞口偏移量并年化。
# Freq5 复用模型1(M0),但在 Gender 翻转后的设计上对其评分。
xgbFreq1_pred <- predict(xgbFreq1, xgbClaimsData_Freq1) / xgb_pred$Exppdays * 365
xgbFreq2_pred <- predict(xgbFreq2, xgbClaimsData_Freq2) / xgb_pred$Exppdays * 365
xgbFreq3_pred <- predict(xgbFreq3, xgbClaimsData_Freq3) / xgb_pred_M3$Exppdays * 365
xgbFreq4_pred <- predict(xgbFreq4, xgbClaimsData_Freq4) / xgb_pred_M4$Exppdays * 365
xgbFreq5_pred <- predict(xgbFreq1, xgbClaimsData_Freq5) / xgb_pred_rev$Exppdays * 365

# 严重程度 DMatrix:此处的 base_margin 是每位保单持有人的预测频率,因此严重程度
# 是以该保单持有人预期理赔的频繁程度为条件建模的。
xgbClaimsData_Sev1 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgbFreq1_pred, drop_vars=drop_common)
xgbClaimsData_Sev2 <- make_xgb_dmatrix(xgb_pred,     base_margin=xgbFreq2_pred, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Sev3 <- make_xgb_dmatrix(xgb_pred_M3,  base_margin=xgbFreq3_pred, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Sev4 <- make_xgb_dmatrix(xgb_pred_M4,  base_margin=xgbFreq4_pred, drop_vars=c(drop_common,"GenderFemale"))
xgbClaimsData_Sev5 <- make_xgb_dmatrix(xgb_pred_rev, base_margin=xgbFreq5_pred, drop_vars=drop_common)

# 严重程度模型直接输出纯保费(严重程度已通过上文的 base_margin 与频率相结合),
# 因此此处无需再单独进行乘法运算。模型5(MC)对 M0 严重程度模型在原始设计与
# Gender 翻转设计上的预测取平均,平均思路与上文 GLM 的 S5/F5 相同。
xgbPrem1_raw <- predict(xgbSev1, xgbClaimsData_Sev1)
xgbPrem2_raw <- predict(xgbSev2, xgbClaimsData_Sev2)
xgbPrem3_raw <- predict(xgbSev3, xgbClaimsData_Sev3)
xgbPrem4_raw <- predict(xgbSev4, xgbClaimsData_Sev4)
xgbPrem5_raw <- 0.5 * (predict(xgbSev1, xgbClaimsData_Sev1) + predict(xgbSev1, xgbClaimsData_Sev5))

# 将每个 XGBoost 模型的组合总额重新缩放至与 GLM MU 的总额(PurePrem2)一致,
# 以便在相同的整体业务规模下比较 GLM 与 XGBoost 模型。
xgbpred_sum <- Dataset_import %>%
  mutate(
    xgbPurePrem1 = xgbPrem1_raw / sum(xgbPrem1_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem2 = xgbPrem2_raw / sum(xgbPrem2_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem3 = xgbPrem3_raw / sum(xgbPrem3_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem4 = xgbPrem4_raw / sum(xgbPrem4_raw) * sum(glmpred_sum$PurePrem2),
    xgbPurePrem5 = xgbPrem5_raw / sum(xgbPrem5_raw) * sum(glmpred_sum$PurePrem2),
    realclaim = Indtppd / Exppdays * 365
  )
```

## 组合层面的调整

GLM 模型3–5以及所有 XGBoost 模型都被按比例缩放,使其预测保费总额与 GLM MU(模型2)的组合总额(即全部100,000份保单的预测保费之和,代表保险公司的完整业务组合)相匹配。这样一来,比较的重点便落在**保费的重新分配**上,而非组合层面的总体差异。

## 公平性指标

**差异性影响比率**(DIR,公平性):受保护群体间平均保费的比率。

$$\text{差异性影响比率} = \frac{\mathbb{E}(\hat{Y} \mid X_P = b)}{\mathbb{E}(\hat{Y} \mid X_P = a)}$$

- 数值越接近1,表示各群体间平均保费越相近。
- 保险行业的五分之四原则:期望该比率落在**0.8至1.25**之间。
- 这正是我们在此检验**人口统计学均等性**的方式,即预测结果在受保护群体间平均而言不应存在差异这一理念。

**RMSE**(准确性):衡量与实际理赔的偏离程度。数值越小越好。

```{r}
# 为每个模型的保费列重新命名为易读的名称(例如"M0: Full Model"),

glm_model_premiums <- glmpred_sum %>%

  )

# 公平性(差异性影响比率) vs. 准确性(RMSE,越低越好)。点线标记五分之四原则
# 区间(0.8-1.25);点划线标记完全公平(比率 = 1)。
ggplot(fairness_accuracy_data, aes(x=rmse, y=disparate_impact_ratio, colour=Model, shape=Method)) +
```

- 靠近虚线($\text{DIR} = 1$)的点最为公平。

- 位置更靠左(RMSE 更低)的点更为准确。

# 保费重新分配

## 谁获益,谁受损?

我们将每一个公平模型与 MU(行业标准的无意识基准模型)进行比较,展示保费在年龄与性别群体间是如何被**重新分配**的。

$$\text{相对保费差异}_{i} = \frac{\bar{Y}_{\text{模型},i} - \bar{Y}_{\text{MU},i}}{\bar{Y}_{\text{MU},i}}$$

正值表示该公平模型对该年龄—性别群体收取的保费**高于** MU。
负值表示收取的保费**低于** MU。

```{r}
#| code-fold: true
#| code-summary: "保费差异图"
#| fig-cap: "相对于 GLM MU 的相对与平均保费差异。"
#| fig-width: 10
#| fig-height: 7

# 每个(年龄、性别)组合的平均预测保费,每个模型一行。下方两张再分配图
# 都是基于这份数据构建的。
premium_difference_by_age <- glmpred_sum %>%
  group_by(Age.ct, Gender) %>%
  summarise(`GLM M0`=mean(PurePrem1), `GLM MU`=mean(PurePrem2),
            `GLM MDP`=mean(PurePrem3), `GLM MCDP`=mean(PurePrem4),
            `GLM MC`=mean(PurePrem5), .groups="drop")

# 每个年龄-性别群体相对于 MU(基准模型)的百分比差异,例如0.10表示该模型
# 对该群体收取的保费比 MU 高10%。
premium_difference_relative <- premium_difference_by_age %>%
  transmute(Age.ct, Gender,
    `GLM M0`  =`GLM M0`  /`GLM MU`-1, `GLM MDP` =`GLM MDP` /`GLM MU`-1,
    `GLM MCDP`=`GLM MCDP`/`GLM MU`-1, `GLM MC`  =`GLM MC`  /`GLM MU`-1) %>%
  pivot_longer(cols=-c(Age.ct,Gender), names_to="Model", values_to="Difference")

# 同样的思路,但改为相对于 MU 的金额(绝对值)差异,而非百分比差异。
premium_difference_average <- premium_difference_by_age %>%
  transmute(Age.ct, Gender,
    `GLM M0`  =`GLM M0`  -`GLM MU`, `GLM MDP` =`GLM MDP` -`GLM MU`,
    `GLM MCDP`=`GLM MCDP`-`GLM MU`, `GLM MC`  =`GLM MC`  -`GLM MU`) %>%
  pivot_longer(cols=-c(Age.ct,Gender), names_to="Model", values_to="Difference")

# 左侧面板:按年龄与性别划分的相对(百分比)保费差异,相对于 MU。虚线在0处
# 标记"与 MU 完全相同";percent_format() 将 y 轴标签格式化为百分比。
p_rel <- ggplot(premium_difference_relative, aes(x=Age.ct, y=Difference, colour=Model, linetype=Gender)) +
  geom_line(linewidth=1) + geom_hline(yintercept=0, linetype="dashed") +
  scale_y_continuous(labels=percent_format(accuracy=1)) +
  labs(x="Age", y="Relative Premium Difference", colour="Model", linetype="Gender") +
  guides(colour=guide_legend(order=1), linetype=guide_legend(order=2)) + theme_minimal()

# 右侧面板:同样的比较,但以金额而非百分比呈现。
p_avg <- ggplot(premium_difference_average, aes(x=Age.ct, y=Difference, colour=Model, linetype=Gender)) +
  geom_line(linewidth=1) + geom_hline(yintercept=0, linetype="dashed") +
  labs(x="Age", y="Average Premium Difference", colour="Model", linetype="Gender") +
  guides(colour=guide_legend(order=1), linetype=guide_legend(order=2)) + theme_minimal()

ggarrange(p_rel, p_avg, common.legend=TRUE, legend="bottom")
```

## 解读重新分配图

- **MDP**(人口统计学均等性):产生最清晰的转移模式,在大多数年龄段内,提高原本收费较低群体的保费,降低原本收费较高群体的保费。
- **MCDP**(条件人口统计学均等性):由于合法变量保持不变,结果更接近 MU。仅有非合法代理变量被去偏。
- **MC**(CPV):重新分配程度居中,仅反映 M0 中的性别系数。

这体现了**团结互助原则**。公平性准则越严格,群体间的交叉补贴就越多。

# 案例研究:审前风险评估(COMPAS)

设想美国某县的刑事法院系统正在决定是否续签一份审前风险评估工具的合同,该工具用于协助法官设定保释与释放条件。这一工具已使用多年,被认为有效减少了不必要的审前羁押,但一项近期的独立审计(呼应了针对真实 COMPAS 工具的 ProPublica 调查报道 [@angwin2016machine])发现,该工具将**不会**再犯的黑人被告标记为高风险的比例,远高于将不会再犯的白人被告标记为高风险的比例。民权倡导者主张应当废除该工具;供应商与部分法官则认为,该工具仍优于不加结构的人工判断,废除它只会让该县回到一个同样未必更公平、只是更不一致的现状。在合同续签表决之前,该县的首席公设辩护人被要求对该工具进行独立评估:它是否满足一项能够在法律挑战下站得住脚的公平性准则?如果不满足,是否可以在不使其失去实用价值的前提下加以修正?

本章此前的内容全部是**回归**问题:预测一个连续的价格。而这一决策不同,它是**二元**的:释放或羁押、标记或放行。第二章中的 M0/MU 模型设计框架原封不动地适用于此。改变的只是模型类型和公平性指标。

我们使用真实的 COMPAS 再犯风险数据集(再犯是指出狱后因新罪行而被逮捕)来评估这一情境,由我们自己拟合模型,并使用 [`fairness`](https://CRAN.R-project.org/package=fairness) R 包 [@kozodoi2021fairness],直接根据群体标签和预测概率计算标准的分类公平性指标。

::: {.callout-tip}
定价案例研究中的同一套工作流程在此同样适用:确定准则 → 选择干预阶段 → 拟合 → 衡量权衡取舍 → 审视受影响对象。改变的只是结果变量(一个二元决策,而非价格)和公平性指标。
:::

- 受保护属性:**族裔**(白人 vs 非裔美国人,这两个最大的群体)
- 预测变量:前科次数、两个年龄段指标、性别、轻罪标志

基础再犯率在不同群体间已存在显著差异,白人为**39.1%**,非裔美国人为**52.3%**。这一单一事实,最终驱动了后文的大部分结果。

## 探索性数据分析

在拟合任何模型之前,值得先检验一下,这一族裔差距在各子群体内是否依然成立,还是实际上只是年龄效应的伪装。

```{r}
#| code-fold: true
#| code-summary: "按族裔与年龄组划分的再犯率"
#| fig-cap: "按族裔与年龄组划分的两年内再犯率。各群体间的差距在每一个年龄段内均持续存在。"
#| fig-width: 7
#| fig-height: 4

# case_when() 将数据中两个 yes/no 年龄段指标列,合并为单一的三水平 AgeGroup
# 因子(自上而下依次判断;TRUE ~ "25-45" 是前两个条件都不满足时的兜底取值)。
compas_eda <- compas_data %>%
  mutate(
    AgeGroup = case_when(
      Age_Below_TwentyFive == "yes" ~ "Under 25",
      Age_Above_FourtyFive == "yes" ~ "Over 45",
      TRUE ~ "25-45"
    ),
    AgeGroup = factor(AgeGroup, levels = c("Under 25", "25-45", "Over 45"))
  ) %>%
  group_by(ethnicity, AgeGroup) %>%
  # mean(Two_yr_Recidivism == "yes") 是"TRUE 所占比例"的简便写法,
  # 即每个族裔—年龄群体内的再犯率;n() 统计每组的行数。
  summarise(RecidivismRate = mean(Two_yr_Recidivism == "yes"), N = n(), .groups = "drop")

# 分组柱状图:每个年龄组对应一对柱子,同一对内每个族裔各一根柱子。
ggplot(compas_eda, aes(x = AgeGroup, y = RecidivismRate, fill = ethnicity)) +
  geom_col(position = "dodge") +
  scale_y_continuous(labels = scales::percent) +
  labs(x = "Age group", y = "Two-year recidivism rate", fill = "Ethnicity") +
  theme_minimal()
```

这一差距在每一个年龄段内都持续存在,幅度从约9个百分点(25–45岁)到约14个百分点(45岁以上)不等。年龄本身并不能解释这一差异,这正是为什么下文的公平性指标需要精确刻画这一差异,而不能仅仅依赖原始比率。

# COMPAS:拟合模型

```{r}
#| code-fold: true
#| code-summary: "拟合 M0 与 MU 逻辑回归"

# family = binomial 拟合的是逻辑回归:结果变量(再犯,是/否)是二元的,
# 不同于上文用 GLM 建模的连续型理赔成本。m0 将族裔作为预测变量;mu 除不含族裔外
# 与 m0 完全相同(即上文定价案例研究中的 M0/MU 模式,应用于分类问题)。
m0 <- glm(Two_yr_Recidivism ~ Number_of_Priors + Age_Above_FourtyFive + Age_Below_TwentyFive +
            Female + Misdemeanor + ethnicity, data = compas_data, family = binomial)

mu <- glm(Two_yr_Recidivism ~ Number_of_Priors + Age_Above_FourtyFive + Age_Below_TwentyFive +
            Female + Misdemeanor, data = compas_data, family = binomial)

# type = "response" 返回再犯的预测概率(0到1之间),而非逻辑回归内部
# 所使用的对数几率(log-odds)尺度。
compas_data$prob_M0 <- predict(m0, type = "response")
compas_data$prob_MU <- predict(mu, type = "response")
```

M0 直接包含族裔变量。MU 移除了该变量,与实际的 COMPAS 工具做法一致,后者并不使用种族作为输入变量。只要模型预测的再犯概率高于此处设定的0.5分界值,该被告便会被标记为高风险。

# COMPAS:结果

## 使用 `fairness` 包计算公平性指标

我们针对 M0 和 MU,分别计算第二章分类体系中的三项群体公平性检验。每一项都使用 `fairness` 包中的一个特定函数,而每个函数具体计算的是哪一个统计量,这一点至关重要:

- **人口统计学均等性**($\hat{Y} \perp X_P$):使用 `prop_parity()`,该函数比较各群体被正向分类的*比例*。(`dem_parity()` 比较的则是*原始计数*,由于两个群体规模差异很大(2,103 对 3,175),这会造成失真,因此对这一准则而言并非正确的函数。)
- **对分离性的部分检验**:`equal_odds()` 仅计算群体的敏感度(真阳性率)。这更接近于*机会均等*,而非要求真阳性率和假阳性率同时均等的完整均衡赔率。我们在下文手动计算并直接报告 FPR 和 FNR,以呈现更完整的图景。
- **对充分性的部分检验**:`pred_rate_parity()` 仅比较精确率(阳性预测值),这只是完整充分性条件 $Y \perp X_P \mid \hat{Y}$ 的一个方向,该条件同时还要求阴性预测值相等。

```{r}
#| code-fold: true
#| code-summary: "计算比例均等性、机会均等与预测率均等性"

# fairness 包的每个函数都会被调用两次,分别针对 M0 与 MU 两个模型,
# 以便比较两个模型各自的差异比率。base = "Caucasian" 设定比率计算所参照的
# 基准群体;cutoff = 0.5 是判定某被告"被标记为高风险"所依据的概率阈值。
pp_m0  <- prop_parity(data = compas_data, outcome = "Two_yr_Recidivism", outcome_base = "no",
                      group = "ethnicity", probs = "prob_M0", cutoff = 0.5, base = "Caucasian")
pp_mu  <- prop_parity(data = compas_data, outcome = "Two_yr_Recidivism", outcome_base = "no",
                      group = "ethnicity", probs = "prob_MU", cutoff = 0.5, base = "Caucasian")
eo_m0  <- equal_odds(data = compas_data, outcome = "Two_yr_Recidivism", outcome_base = "no",
                      group = "ethnicity", probs = "prob_M0", cutoff = 0.5, base = "Caucasian")
eo_mu  <- equal_odds(data = compas_data, outcome = "Two_yr_Recidivism", outcome_base = "no",
                      group = "ethnicity", probs = "prob_MU", cutoff = 0.5, base = "Caucasian")
prp_m0 <- pred_rate_parity(data = compas_data, outcome = "Two_yr_Recidivism", outcome_base = "no",
                      group = "ethnicity", probs = "prob_M0", cutoff = 0.5, base = "Caucasian")
prp_mu <- pred_rate_parity(data = compas_data, outcome = "Two_yr_Recidivism", outcome_base = "no",
                      group = "ethnicity", probs = "prob_MU", cutoff = 0.5, base = "Caucasian")
```

|-------|----------|---------------------------------------------------|-------------------------------------|-------------------------------------|--------------------------------------------|
| M0(含族裔变量) | 66.8% | 25.1% / 52.9% | 15.9% / 35.3% | 60.7% / 31.1% | 61.3% / 68.2% |
| MU(无意识) | 66.5% | 26.1% / 50.6% | 17.2% / 33.0% | 60.0% / 33.4% | 59.9% / 68.9% |

| 准则 | M0 差异比率 | MU 差异比率 |
|-----------|--------------------|---------------------|
| 人口统计学均等性(`prop_parity`) | **2.11** | **1.94** |
| 机会均等/TPR 差距(`equal_odds`) | 1.75 | 1.67 |
| 预测率均等性/精确率差距(`pred_rate_parity`) | 1.11 | 1.15 |

## 解读结果

无意识几乎没有改变任何东西。MU 几乎不损失任何准确率(66.5% 对比 66.8%),但无论模型是否直接看到族裔变量,每一项差异比率都几乎原封不动地保留了下来。一名**不会**再犯的非裔美国被告,被标记为高风险的概率,大约是一名不会再犯的白人被告的两倍(FPR 差距:MU 下为33.0% 对比17.2%)。这与 ProPublica 针对实际 COMPAS 工具所报告的发现在性质上完全一致 [@angwin2016machine],而在这里,仅使用四个通用预测变量的一个简单逻辑回归模型,便复现了这一结果。

这三项检验对差异**究竟有多严重**的判断存在显著分歧,而这种分歧本身正是本例的教训所在。

::: {.callout-important}
**人口统计学均等性显示出最大的差距(比率≈2),TPR/机会均等差距为中等程度(比率≈1.7),而精确率差距则相对较小(比率≈1.1)。** 这并非三个独立的发现——而是同一个发现在不同统计量视角下的呈现。人口统计学均等性完全忽略真实结果,因此除了模型本身的不公平之外,它还完全反映了基础再犯率之间的潜在差距(39.1% 对比52.3%)。精确率则以预测结果为条件,因而部分吸收了同样的基准率差距。第二章“分离性与充分性”专栏已经指出,当基准率不同时,分离性与充分性通常无法同时满足,完美预测等特殊情形除外。这正是那一不可能性结论在真实数据上的体现,而非纯理论上的趣味结果。**选择一项准则,就是在选择基准率差异中有多少应被计入“不公平”,又有多少应被视为“信号”。**
:::

在拟合之前对预测变量应用 MDP 或 MCDP 式的去偏处理(与上文定价案例研究中的做法完全一致),会使这些比率更接近1,但同时也会带来一定的准确性代价。这与上文已经探讨过的权衡取舍完全相同,只是这里以分类差异比率而非保费的差异性影响比率来衡量。

# COMPAS:后处理修正

## 实现某一准则:使用 `roc_pivot()` 进行后处理

`fairness` 包只能*衡量*差异,不提供修正方法。`fairmodels`(上文已用于保险差异性影响消除器)也提供了**后处理**功能。`roc_pivot()` 实现了一种拒绝选项修正 [@kamiran2012decision],它对落在决策分界值附近、宽度为 `theta` 的区间内的预测结果重新贴标签,给予处于弱势群体的边界个案以有利推定,同时将处于优势群体的边界个案推向相反方向。

从机制上看,这相当于以分界值为中心做镜像翻转:边界概率 $p$ 变为 $2 \times \text{分界值} - p$。原本刚好被预测为有利结果的优势群体个案,会被翻转为不利结果;原本刚好被预测为不利结果的弱势群体个案,会被翻转为有利结果。区间之外、模型有把握的预测则保持不变。

`roc_pivot()` 假定高于分界值的概率代表*有利*结果,且 `privileged` 参数所指定的是*优势*群体。在我们的模型中,高于0.5的概率意味着预测再犯,即不利结果,因此在调用 `roc_pivot()` 之前,我们先将模型转换为预测**不再犯**这一有利结果,并保持白人(现状模型所偏向的群体)为优势群体。这样一来,函数各参数的含义便与其名称所表达的一致,而不必依赖两次相互抵消的方向反转来得到正确的结果。

```{r}
#| code-fold: true
#| code-summary: "在多个 theta 取值下对 MU 进行 roc_pivot 后处理"
#| message: false
library(DALEX)

# 有利结果:不再犯
y_favourable <- as.integer(compas_data$Two_yr_Recidivism == "no")

# 将拟合模型的再犯概率,转换为不再犯概率
predict_non_recidivism <- function(model, newdata) {
  1 - predict(model, newdata = newdata, type = "response")
}

# roc_pivot()(来自 fairmodels)不能直接作用于原始的 glm 对象;它需要一个
# DALEX "explainer" 包装器,将模型与其数据、真实结果,以及(此处)一个自定义
# predict_function 打包在一起,使 roc_pivot() 看到的是不再犯的概率。
mu_explainer <- DALEX::explain(
  mu, data = compas_data, y = y_favourable,
  predict_function = predict_non_recidivism, verbose = FALSE
)

# 真正执行后处理修正的一行:对落在0.5分界值附近、宽度为 theta 的区间内的预测
# 重新贴标签,将边界个案推向有利于非优势群体的结果。用不同的 theta 值重新运行
# 这一行,即可复现下方表格中的结果。
mu_fixed <- roc_pivot(mu_explainer, protected = compas_data$ethnicity,
                       privileged = "Caucasian", cutoff = 0.5, theta = 0.05)

# roc_pivot 返回的是经调整后的不再犯概率;
# 转换回再犯概率,以便下游代码保持原有的记法约定。
compas_data$prob_MU_fixed <- 1 - mu_fixed$y_hat
```

| theta | 准确率 | 人口统计学均等性 | 机会均等(TPR 差距) | 预测率均等性 |
|-------|----------|---------------------|------------------------------|--------------------------|
| 0(MU,未修正) | 66.5% | 1.94 | 1.67 | 1.15 |
| 0.05 | 65.7% | 1.13 | 1.11 | 1.31 |
| 0.10 | 62.8% | 0.63 | 0.69 | 1.45 |
| 0.15 | 59.4% | 0.34 | 0.40 | 1.59 |
| 0.20 | 56.8% | 0.23 | 0.30 | 1.73 |

## 解读这一权衡取舍

在 `theta = 0.05` 时,以有限的准确性代价(66.5% → 65.7%)换来了人口统计学均等性的大幅改善(1.94 → 1.13),并使 TPR 差距几乎恰好达到均等(1.67 → 1.11)。这看起来像是天上掉馅饼,直到我们同时读一下预测率均等性这一列。

::: {.callout-important}
**随着修正力度增强,预测率均等性单调地变得*更差***,`theta` 从0增至0.20时,该指标从1.15(勉强违反)升至1.73(严重违反)。将人口统计学均等性和 TPR 差距推向1,并不会让精确率差距保持不变——反而会主动使其扩大。超过 `theta ≈ 0.10` 之后,人口统计学均等性和 TPR 差距**会下冲到1以下**,这意味着此时的修正已经将差异反转,而非消除,同时准确性代价陡增(66.5% → 56.8%,几乎不比抛硬币好多少)。

这正是第二章的不可能性结论,以一个可调“旋钮”、而非单一的前后对比快照的形式呈现出来。不存在能够同时满足这三项检验的 `theta` 值,因为只要这两个群体的基础再犯率存在差异,这样的值就根本不存在。后处理让你可以选择*落在这条曲线上的哪个位置*,但无法让你逃离这条曲线本身。
:::

# 小结

- 全部四种反歧视模型设计,均可在真实保险数据上以有限的准确性代价加以实现,而同样的工作流程(确定准则 → 选择阶段 → 拟合 → 衡量权衡取舍 → 审视重新分配)也可迁移至其他领域,包括上文的二元分类(COMPAS)场景。
- 模型的选择应当**遵从第二章中所选定的监管准则**,而非建模上的便利性。
- MDP 带来最强的群体公平性,但也带来最大幅度的结果重新分配。MCDP 则更具针对性。
- 无意识(MU)本身很少足够。COMPAS 案例研究表明,即便在完全脱离保险业的二元分类场景下,这一结论依然成立。
- 后处理可以将一个分类器推向任意一项群体公平性检验的达标,但无法同时满足全部三项。在 COMPAS 实例中,将 TPR 差距和人口统计学均等性推向均等,反而主动恶化了预测率均等性。选择一种修正方法,与第二章第一步中选择一项准则,是密不可分的。
